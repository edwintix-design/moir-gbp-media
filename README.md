# Moir GBP Media

Aset gambar publik untuk **Google Business Profile Posts** Moir Salon.

Google Business Profile API mengambil gambar lewat URL publik (`media.sourceUrl`),
jadi folder ini memang harus bisa diakses publik — itu syarat teknis, bukan kelalaian.

## Isi
Foto/poster lokasi per outlet (materi marketing yang sudah tayang publik di listing
Google Maps Moir Salon). Tidak ada data internal, harga wholesale, atau data karyawan.

## Aturan
- **Hanya materi marketing yang sudah publik.** Jangan pernah menaruh file internal di sini.
- Gambar yang sudah dipakai di post GBP **di-cache Google** — menghapus file di sini
  tidak menghapus gambar dari post yang sudah tayang.

Dipakai oleh robot `moir-gbp-robot` (auto-post mingguan).
